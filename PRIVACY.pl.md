# Prywatność

[English](PRIVACY.md)

## Dostęp do skarbca

Code Embed sprawdza lokalne ścieżki plików, aby znaleźć znaczniki pakietów i rozróżnić pasujące pliki. Okno wyboru folderu wyświetla foldery skarbca. Wyszukiwanie linków zwrotnych, sprawdzanie niedziałających odwołań i aktualizowanie odwołań podczas zmiany nazw mogą wymagać odczytu notatek Markdown z całego skarbca. Wtyczka odczytuje poszczególne notatki, aby rozwinąć osadzone fragmenty. Podczas rozwijania fragmentu w pakiecie wybiera cele w granicach tego pakietu. Te operacje korzystają z lokalnego API Obsidiana.

## Dostęp do schowka

Gdy użyjesz Copy+ lub polecenia kopiowania rozwiniętej treści, Code Embed zapisze rozwinięty tekst wybranego bloku do schowka systemowego. Wtyczka nie odczytuje schowka.

## Linki zewnętrzne

Polecenie wsparcia otwiera stronę wybranego operatora płatności w zewnętrznej przeglądarce.
