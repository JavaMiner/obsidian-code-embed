# AT-30 · a replaced package marker survives a pending confirmation

Adres: [[Automaty/AT-30]] · [[Indeks testów]]

## Wpisz w terminalu

```shell
npx tsx --test --test-name-pattern "^a replaced package marker survives a pending confirmation$" test/startup.test.ts
```

## Oczekiwany efekt

W raporcie testów pojawi się zaliczony przypadek **a replaced package marker survives a pending confirmation**. Liczba niepowodzeń wynosi zero.
