# CE-10 · Argument z przecinkiem

Adres: [[Próby/CE-10]] · [[Indeks testów]]

## Wpisz

`![CE-Etykiety:<<lista>>("A, B", C)]`

Umieść ten wiersz w bloku kodu oznaczonym `text`.

## Oczekiwany efekt

Cudzysłów chroni przecinek w pierwszym argumencie. Ostatnie pole łączy wszystkie argumenty.

```text
A, B / C / A, B, C
```
